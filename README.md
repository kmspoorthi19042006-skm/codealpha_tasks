# CodeAlpha Full Stack Development Internship

A collection of three full-stack web development projects completed as part of the **CodeAlpha Full Stack Development Internship – September 2026 Batch**.

A full-stack e-commerce platform with product browsing, shopping cart, authentication, checkout, and order management.

**Technologies:**
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- JWT
- bcrypt.js

**Features:**
- User registration and login
- JWT authentication
- Product listings
- Product details
- Shopping cart
- Stock validation
- Checkout
- Shipping address
- Order processing
- My Orders
- Order details
- MySQL database persistence
